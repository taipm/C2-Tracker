# C2-Tracker desktop app (UI mock scaffold)

Tauri v2 + Rust backend + vanilla HTML/CSS/JS frontend. UI hiển thị mock data để
owner xem layout & cảm nhận sản phẩm. Chưa có DB / watcher / hooks thật.

## Chạy lần đầu

```bash
cd app
./setup.sh
```

`setup.sh` sẽ:

1. Sinh placeholder icons (`src-tauri/icons/*.png`) bằng Python stdlib.
2. Cài `cargo-tauri` ^2.0 nếu chưa có.
3. Chạy `cargo tauri dev`.

## Chạy thủ công

```bash
cd app
python3 gen_icons.py          # 1 lần duy nhất
cargo install tauri-cli --version "^2.0" --locked   # 1 lần duy nhất
cargo tauri dev
```

## Tauri commands

| Command | Args | Returns |
|---|---|---|
| `get_sessions` | — | `Session[]` |
| `get_events` | `{ sessionId }` | `Event[]` |
| `get_stats` | — | `QuickStats` |

Tất cả trả mock data từ `src-tauri/src/mock.rs`.

## Tương tác

- Click session ở sidebar → load stream.
- Click thinking block → expand/collapse reasoning.
- Click tool_use/tool_result → expand input/output JSON (pretty printed).
- `Cmd+K` / `Ctrl+K` → mở command palette tìm session.
- `↑↓` (ngoài input) → chuyển session.
- Auto-follow checkbox: UI dummy, chưa wire.

## Mở trong browser (không cần Tauri)

Mở `src/index.html` bằng Live Server hoặc bất kỳ static server nào — `app.js`
có in-browser fallback với 1 session + 3 event để xem layout nhanh khi không
cần build full Tauri.
